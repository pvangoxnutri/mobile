# SideQuest Symbol Language System

A premium, emotionally warm icon system that feels unique to SideQuest travel. Not corporate. Not emoji. Not startup aesthetics. **Warm minimalism with hidden depth.**

---

## 1. ICON DNA

### Visual Foundation

**Stroke Philosophy:**
- **Primary stroke width**: 1.5px (optical weight)
- **Secondary accent**: 2px (emphasis moments only)
- **Minimum stroke**: 1px (fine detail, rare)
- **Consistency rule**: Stroke width constant throughout single icon
- **Optical balance**: Heavier strokes for complex geometry, lighter for simple forms

**Corner & Curves:**
- **Default corner radius**: 12-16% of stroke width (subtle, not rounded)
- **Never fully rounded**: Maintains sophistication and intentionality
- **Curve approach**: Organic, human-drawn feeling (not mathematically perfect arcs)
- **Transition zones**: Smooth, never abrupt joins

**Outline vs Fill Philosophy:**
- **Primary rule**: Outline-only system (98% of icons)
- **When filled**: Only for small accent marks (dots, highlights, badges)
- **Fill usage**: Never entire icon, only meaningful moments
- **Negative space**: Integral to the design (not just background)

**Geometric Style:**
- **Foundation**: Modern geometric (not organic, not skeuomorphic)
- **Warmth technique**: Softened intersections, subtle asymmetry, human-drawn imperfection
- **Not perfectly mathematical**: Slight weight variations suggest intentionality
- **Inspiration sources**: Architecture, map markers, constellation fragments, folded paper—NOT emoji

**Icon Density:**
- **Space within**: Icons breathe; negative space is active design
- **Line complexity**: Maximum 4-5 distinct strokes per icon (simplicity rule)
- **Visual noise**: None; every element carries meaning
- **Whitespace**: 30-40% of icon bounding box

**Optical Balance:**
- **Weight distribution**: Slightly bottom-heavy (travel, grounding metaphor)
- **Visual center**: Varies by icon; never assume geometric center
- **Compensate for curves**: Curved strokes appear lighter; adjust weight accordingly
- **Isolated testing**: Every icon evaluated alone, not in context (prevents grouping errors)

**Shadow & Depth:**
- **Core philosophy**: No shadows (maintains premium flatness)
- **Exception**: Overlay/hover states only (ultra-subtle, 2% opacity black)
- **Depth technique**: Stroke weight and opacity, never shadow effects
- **3D elements**: Forbidden (this isn't skeuomorphic)

**Opacity Philosophy:**
- **Baseline**: 100% (always opaque)
- **Disabled state**: 50% opacity (clear hierarchy)
- **Hover/subtle states**: 70% (tactile feedback)
- **Animated reveal**: Fade in from 0 → 100% (not easing bounce)

**Animation Behavior:**
- **Entrance**: Fade-in over 240ms (soft, patient)
- **Micro-interactions**: 120ms scale (0.96 → 1.0) on tap
- **Continuous animation**: Only for specific symbols (countdown, loading) — max 1 loop per 4 seconds
- **No wiggle/bounce**: Ever. No playfulness.
- **Anticipation support**: Icons should prime the user for interaction, not demand attention

## 2. SIDEQUEST CORE SYMBOLS

These are the ownable, emotionally intelligent symbols unique to SideQuest.

### Hidden SideQuest Symbol
**Concept**: Mystery + anticipation + safety (locked, not lost)

**Visual Direction:**
- **Primary**: Abstracted lock shape—not literal padlock
- **Metaphor**: Folded envelope or treasure chest suggestion
- **Composition**: Geometric frame with subtle center void
- **Stroke approach**: Outline with one internal line dividing presence/absence
- **Emotional tone**: Safe, curious, not threatening
- **Size variation**: Same DNA at 16px (badge) and 24px (header)

**Philosophy**: 
The hidden symbol should feel like a gentle gate, not an alarm. Suggests mystery but radiates calm. The lock isn't aggressive—it's protective.

---

### Reveal Symbol
**Concept**: Unlocking moment + clarity + joy

**Visual Direction:**
- **Primary**: Lock + subtle sparkle suggestion (not separate elements)
- **Metaphor**: Opening, light entering, moment of clarity
- **Composition**: Lock form where top third suggests dispersing/opening upward
- **Stroke approach**: Outline; no fill except one small accent dot (light/spark)
- **Animation**: On reveal, the icon itself can subtly shift (spark accent moves, top suggests opening)
- **Emotional tone**: Gentle surprise, warm moment

**Philosophy**: 
Feels like the inverse of Hidden. Should read as "lightness" and "unveiling" without being flashy. Spark is minimal—maybe just a single dot or a subtle glow-like line fragment.

---

### Anticipation Symbol
**Concept**: Countdown + waiting + soft time pressure

**Visual Direction:**
- **Primary**: Abstract hourglass or time fragments
- **Metaphor**: Time flowing, passage of moment, sand or light moving downward
- **Composition**: Two abstract shapes suggesting upper/lower (not literal hour glass)
- **Stroke approach**: Outline; center void shows time passage
- **Animation**: Gentle opacity pulse (80% → 100%) or very subtle downward movement (2-3px over 3 seconds)
- **Emotional tone**: Patient, not urgent. Builds calm anticipation, not anxiety.

**Philosophy**: 
Not a traditional timer. More poetic. Suggests the passage of time as a beautiful thing ("Soon this will be revealed") not as urgency ("Hurry!").

---

### Adventure Symbol
**Concept**: Journey + discovery + open possibility

**Visual Direction:**
- **Primary**: Abstracted route or path
- **Metaphor**: Winding road, constellation connection, journey without knowing destination
- **Composition**: 2-3 connected points or flowing path (never straight line)
- **Stroke approach**: Outline; path curves gently
- **Variation**: Can have slight compass rose suggestion (one point emphasized)
- **Emotional tone**: Open, curious, warm discovery

**Philosophy**: 
Represents the trip itself—not a destination. Should suggest motion and exploration. Slightly organic (not perfectly geometric) to feel human-scaled.

---

### Travel Memory Symbol
**Concept**: Moment captured + emotional permanence + archive

**Visual Direction:**
- **Primary**: Abstracted frame or landmark silhouette
- **Metaphor**: Photo frame, folded map, key moment marker
- **Composition**: Simple geometric frame with one internal element (mountain, building, or abstract shape)
- **Stroke approach**: Outline only; internal element can be minimal line work
- **Emotional tone**: Warm, nostalgic, precious

**Philosophy**: 
Feels like a keepsake. Not a camera icon—more like a memory token. Should work at small sizes and feel meaningful even as a favicon.

---

### Mystery Symbol
**Concept**: Hidden depth + intrigue + elegant unknown

**Visual Direction:**
- **Primary**: Fragmented or scattered geometric shapes (constellation-inspired)
- **Metaphor**: Hidden puzzle, mystery unfolding, abstract map
- **Composition**: 3-4 disconnected points that suggest a larger pattern
- **Stroke approach**: Outline; subtle connecting lines (optional, can be very faint)
- **Emotional tone**: Intriguing without being chaotic, elegant fragmentation

**Philosophy**: 
Suggests something larger just beyond visibility. Should feel premium and mysterious, not random or broken.

---

### Shared Moments Symbol
**Concept**: Connection + togetherness + social warmth

**Visual Direction:**
- **Primary**: Abstract convergence of paths or voices
- **Metaphor**: Multiple journeys meeting, shared experience marker, social constellation
- **Composition**: 2-3 geometric shapes converging or touching
- **Stroke approach**: Outline; convergence point can be subtly emphasized
- **Emotional tone**: Warm, intimate, celebratory but restrained

**Philosophy**: 
Feels like people gathering without showing people. Abstract enough to be versatile. Should suggest connection as a meaningful moment, not just collaboration.

---

### Exploration Symbol
**Concept**: Discovery + openness + wonder

**Visual Direction:**
- **Primary**: Compass or directional abstraction
- **Metaphor**: Finding direction, open horizon, new territory
- **Composition**: Four or eight-point directional suggestion (not traditional compass rose)
- **Stroke approach**: Outline; center void suggests the explorer's viewpoint
- **Emotional tone**: Curious, open, adventurous but calm

**Philosophy**: 
More modern and minimal than a traditional compass. Should feel like standing at a crossroads with possibility ahead.

---

### Routes & Journeys Symbol
**Concept**: Path + waypoint + structure of travel

**Visual Direction:**
- **Primary**: Connected waypoints or path nodes
- **Metaphor**: Journey stages, milestones, structured travel
- **Composition**: 3-4 dots or nodes connected by flowing lines
- **Stroke approach**: Outline only; nodes can have subtle emphasis
- **Animation**: On important moments, nodes can subtly pulse (not all at once, sequential)
- **Emotional tone**: Purposeful, structured discovery

**Philosophy**: 
Suggests narrative structure to the journey. Each point is meaningful. Should feel like planning and adventure combined.

---

### Time/Countdown Symbol
**Concept**: Passage + moment arriving + temporal awareness

**Visual Direction:**
- **Primary**: Abstract clock or time marker
- **Metaphor**: Moment approaching, time flowing, ephemeral beauty
- **Composition**: Minimal line work suggesting time (can be asymmetrical, not circular)
- **Stroke approach**: Outline; no traditional clock hands
- **Animation**: Can subtly shift or fade to suggest time passing
- **Emotional tone**: Precious, not anxious. Time as a gift, not pressure.

**Philosophy**: 
Feels premium and poetic, not functional. Time in SideQuest is about beautiful moments arriving, not productivity.

## 3. CATEGORY SYMBOL SYSTEM

Practical icons for activity categories. These follow core DNA but serve functional needs.

### Flight
**Visual**: Minimalist aircraft silhouette suggestion or trajectory line

**Details:**
- Outline only, 1.5px stroke
- Simple geometric form (not detailed airplane)
- Suggest motion or altitude
- Works at 16px and up

**Emotional tone**: Departure, movement, expansion

---

### Food
**Visual**: Abstract dining element or consumption marker

**Details:**
- Utensil abstraction or plate edge suggestion
- Outline, 1.5px stroke
- Minimal, not appetizing imagery
- Suggests gathering as much as eating

**Emotional tone**: Shared pleasure, discovery, sensory moment

---

### Stay
**Visual**: Shelter or place marker

**Details:**
- Roof line or geometric shelter suggestion
- Outline, 1.5px stroke
- Minimal interior detail (if any)
- Warm, not corporate

**Emotional tone**: Rest, arrival, home-away-from-home

---

### Sightseeing / Sight
**Visual**: Vista or landmark marker

**Details:**
- Frame or viewpoint suggestion
- Outline, 1.5px stroke
- Optional internal landmark silhouette (mountain, building, horizon)
- Suggests beauty and viewpoint

**Emotional tone**: Wonder, visual moment, discovery

---

### Transport
**Visual**: Route or movement marker

**Details:**
- Path or vehicle suggestion
- Outline, 1.5px stroke
- Motion implication (flow lines optional, minimal)
- Functional but warm

**Emotional tone**: Journey, logistics, connection

---

### Hidden SideQuest (Category)
**Visual**: Uses core Hidden Symbol

**Details:**
- Consistent with core Hidden symbol
- Maintains lock + void composition
- Recognizable at all sizes

**Emotional tone**: Mystery, protection, anticipation

---

### Other / Default
**Visual**: Abstracted experience marker or open symbol

**Details:**
- Open geometric form (incomplete circle, open frame)
- Outline, 1.5px stroke
- Suggests flexibility and possibility
- Acts as "everything else"

**Emotional tone**: Open-ended, inclusive, possibility

## 4. VISUAL PHILOSOPHY

### The Emotional Voice

**Core Feelings:**
- Warm (not cold corporate)
- Minimal (not decorated)
- Premium (not cheap)
- Mysterious (not obvious)
- Social (not isolated)
- Calm (not frenetic)
- Intentional (not accidental)

### Design Principles

**Premium through Restraint:**
- Fewer lines = more significance
- White space is as important as strokes
- Every detail earns its place
- No decoration without purpose

**Warm Through Imperfection:**
- Subtle asymmetries (not mathematically perfect)
- Hand-drawn quality (not mechanical)
- Weight variations (not uniform)
- Human scale (feels designed for real people)

**Modern But Timeless:**
- Contemporary geometry (not skeuomorphic)
- Timeless proportions (not trendy)
- Clear at small sizes (functional)
- Beautiful at large sizes (refined)

**Travel-Specific Emotion:**
- Icons suggest movement and discovery
- Geography metaphors (compass, map, path)
- Social connection (shared moments)
- Time as precious (anticipation, memory)

### Forbidden Aesthetics
- ❌ Emoji-like roundness or character
- ❌ Corporate SaaS (clean but soulless)
- ❌ Crypto/startup (aggressive, trendy)
- ❌ Playful internet app (cuteness)
- ❌ Productivity dashboard (functional-only)
- ❌ Gaming UI (bright, attention-grabbing)
- ❌ Illustration (detailed, narrative)

## 5. MOTION BEHAVIOR

### Philosophy: Support, Not Distract

Icons animate to **prime anticipation** and **provide tactile feedback**, never to grab attention or be cute.

### Entrance Animation
**When**: Icon first appears on screen

**Behavior:**
- Fade in: 0% opacity → 100%
- Duration: 240ms
- Easing: ease-out (fast start, gentle landing)
- Stagger: If multiple icons, 40-60ms offset
- NOT: Scale, rotate, or bounce

**Emotional effect**: Gentle arrival, calm introduction

---

### Interaction Animation (Tap/Press)
**When**: User taps or presses icon button

**Behavior:**
- Scale: 1.0 → 0.92 (press down)
- Duration: 120ms total (70ms press, 50ms release)
- Easing: ease-in-out
- Opacity: Subtle (no change or -10% max)
- Haptic: Light impact (if interaction is significant)

**Emotional effect**: Tactile feedback, confirmation, responsiveness

---

### Micro-state Animation (Hover on Web)
**When**: User hovers on interactive element

**Behavior:**
- Opacity: 100% → 85%
- Duration: 160ms
- No scale or rotation
- Applies to whole container, not just icon

**Emotional effect**: Subtle readiness, inviting interaction

---

### Continuous Animation (Special Cases)
**When**: Icon represents active state (countdown, loading, anticipation)

**Use Cases:**
- **Anticipation symbol during countdown**: Gentle pulse (80% → 100% opacity) over 2-3 seconds, maximum one cycle per 4 seconds
- **Loading/sync in progress**: Subtle rotation (360° over 3-4 seconds) or opacity pulse, very restrained
- **Reveal moment**: Icon can transition (lock → sparkle form) over 400ms with 20% scale up, then settle

**Constraints:**
- One motion per icon at a time
- Never attention-seeking
- Respects reduced-motion preferences
- Communicates state, not entertainment

---

### Reveal Symbol Special Motion
**When**: Hidden SideQuest reveals

**Behavior:**
- Lock form subtly opens/disperses at top
- Sparkle accent moves or appears
- Duration: 400ms
- Easing: ease-out (decelerate)
- Followed by haptic feedback (medium impact)
- Can be combined with scale (1.0 → 1.08 → 1.0) for emphasis

**Emotional effect**: Magical moment, but restrained and premium

---

### Motion Do's & Don'ts

**✅ Do:**
- Fade in/out
- Subtle scale (0.92 - 1.08 range)
- Gentle opacity (50% - 100% range)
- Soft pulses (2-3 second cycles)
- Easing curves (ease-in-out, ease-out)
- Haptic pairing

**❌ Don't:**
- Rotate continuously (unless specifically loading state)
- Bounce or overshooting
- Multiple simultaneous animations
- Animations longer than 400ms (except continuous states)
- Wiggle or jitter
- Call attention through motion

## 6. IMPLEMENTATION STRATEGY

### Icon Hierarchy System

**Size Tiers:**
- **12px**: Navigation tabs, small badges, inline labels (simplified forms)
- **16px**: List items, secondary UI, form fields (core icon)
- **20px**: Buttons, headers, cards (full detail)
- **24px**: Large buttons, prominent sections (maximum detail)
- **28px+**: Hero moments, isolated displays (can have more nuance)

**Scaling Rules:**
- Icons should scale perfectly from 12px → 28px
- Core shapes readable at all sizes
- Fine detail only added at 20px+
- No detail should disappear when scaling down

---

### Reusable Icon DNA Variables

**Stroke Weight:**
- Small (12-16px): 1.5px stroke → appears as 1px optical weight
- Medium (20-24px): 1.5px stroke → intended thickness
- Large (28px+): 1.5px stroke with slight weight emphasis possible

**Spacing Rules:**
- Padding within icon bounding box: 2-3px minimum
- Icon to text spacing: SPACING.xs (4px)
- Icon to icon spacing: SPACING.sm (8px)
- Grouped icons: Center alignment standard

**Opacity Usage:**
- Enabled/interactive: 100%
- Hover state: 85%
- Disabled state: 50%
- Subtle background: 60%
- Faded context: 40%

---

### Outline vs Fill Matrix

| Context | Rule |
|---------|------|
| Primary navigation | Outline only (always) |
| Action buttons | Outline only (always) |
| Status badges | Outline + single accent fill dot (optional) |
| Category icons | Outline only (always) |
| Loading states | Outline only |
| Core symbols | Outline only |
| Disabled states | Outline, 50% opacity |

**Exception philosophy**: Fill is allowed ONLY for:
- Single accent dots (highlight, notification)
- Filled badges (status moments)
- Small interior marks (emphasis)
Never fill the entire icon.

---

### Consistency Guidelines for Future Icons

**Design Checklist:**
Before finalizing any icon:

1. **DNA Compliance**
   - [ ] 1.5px stroke weight
   - [ ] 12-16% corner radius (if applicable)
   - [ ] No fills (except accent marks)
   - [ ] 30-40% negative space
   - [ ] Bottom-heavy visual weight

2. **Emotional Tone**
   - [ ] Feels warm, not corporate
   - [ ] Feels intentional, not accidental
   - [ ] Fits travel/discovery narrative
   - [ ] Supports SideQuest emotional voice

3. **Functional Testing**
   - [ ] Readable at 12px (simplified version)
   - [ ] Works at 24px (full detail)
   - [ ] Clear in isolation (not dependent on color)
   - [ ] Clear when disabled (50% opacity)

4. **Motion Readiness**
   - [ ] Stable form for fade-in animation
   - [ ] No elements that should never move
   - [ ] Symmetric enough for scale animation
   - [ ] Key elements positioned for optical balance

5. **Premium Quality**
   - [ ] No over-designed flourishes
   - [ ] Stroke weight consistent
   - [ ] Curves smooth and intentional
   - [ ] Negative space is active design
   - [ ] Feels premium, not corporate

## 7. THE SIDEQUEST ICON VOICE

### What This System Says

This icon system communicates:
- **"We understand travel emotion"** (not just logistics)
- **"We're premium but approachable"** (not corporate, not startup)
- **"We celebrate the hidden moments"** (mystery + anticipation + reveal)
- **"You're safe to explore"** (warm, intentional, calm)
- **"Time here is precious"** (not productivity, but memory)
- **"This is social"** (shared adventures matter)

### Long-term Recognition

Over time, these icons should become:
- **Memorable** (unique, not generic app icons)
- **Ownable** (people recognize them as SideQuest-specific)
- **Timeless** (don't feel dated after a year)
- **Emotionally resonant** (people feel something when they see them)
- **Functionally clear** (users understand them instantly)

### The Aspiration

These icons should feel like **"designed by someone who loves travel"**—not "created from an icon pack."

## 8. GETTING STARTED

### Phase 1: Core Symbols
Build the 10 core symbols first (Hidden, Reveal, Anticipation, etc.). These define the visual language.

### Phase 2: Category System
Apply DNA to category icons, ensuring consistency with cores.

### Phase 3: Systematic Coverage
Identify gaps (navigation, states, actions) and fill with consistent DNA.

### Phase 4: Animation & Implementation
Define exact motion curves and implement in code.

### Phase 5: Refinement
Live testing, visual consistency audits, emotional impact validation.
